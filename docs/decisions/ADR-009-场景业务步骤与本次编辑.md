# ADR-009：场景业务步骤与本次编辑

状态：已采用，2026-10-20 用户确认；实现为本地候选。

## 决定与背景

用户反馈嵌套步骤无法收折、处理节点难读、配置与输入映射重复，并要求步骤内编辑与统一参数同步、登录身份可切换、引用显示来源步骤。

目录按调用层级折叠。连续消费同一业务调用产出的提取、计算、校验归入该业务步骤的“结果处理与校验”；流程开头的本地校验与准备放进该调用的“执行前检查与准备”。跨业务步骤的计算或汇总保留独立展示。分组只改变浏览方式，原始执行顺序、step_id、结构编号与失败停止规则保持；不凭相近名称把不连续操作移动到前面。

步骤输入与外层本次参数是同一份工作副本，生效基线沿用 ADR-003 的顶层替换。流程 inputs 必须沿每个调用点显式绑定追溯到根参数，map 的 item 指向所选输入数组项；编辑保留同顶层键的兄弟字段和数组顺序。运行期输出显示来源并只读，不把响应值写回根参数。原始引用按需保留；数据来源、读取路径、筛选条件各显示一次，不再重复成通用输入映射。

编辑只影响本次运行，切换场景/项目/环境清除工作副本；共享参数仍通过既有显式保存、revision/CAS 维护，不自动保存。账号不是业务参数：本次步骤身份使用单独的调用路径覆盖，不能把凭据放入场景参数。

## 调用身份与影响

schema 0.3 本次覆盖采用 step_id/child_id 路径，区分重复引用同一 flow 的不同调用。map 子步骤选择的身份适用于全部迭代，不支持每一项不同的临时账号。覆盖优先于资产显式 identity；省略恢复资产定义，none 为显式匿名。未知路径、非 API 目标、未知/不可用身份均在首个业务请求前拒绝。实际请求与历史 auth 使用所选身份，不改账号凭据、资产 YAML 或接口契约。

旧 0.2 场景不接受此覆盖，不默默忽略。远程 Engine 0.6.0 锁定包原本不含该扩展，本地候选通过显式本地开发入口验证；远程交付时仍须先交付新 Engine、再精确锁 Control。不能以页面可选代替执行链路已支持。

## 原因与未采用方案

不为了减少目录项删除 Engine 中独立提取/断言节点；那会改变可复用性、预检与失败证据。也不把所有处理强行附在上一个 API 下，跨步骤计算需要保留其真实依赖位置。页面用业务说明解释处理含义，例如“逐项读取 quantity，检查为正整数后相加”，而非只显示操作符。

当前定义的来源导航根据调用局部 alias 解析，显示来源序号和名称；历史来源按当次 trace 构建，不读取最新定义。分组之后仍能逐项查看原配置和失败证据。个人变量草稿按下述补充决定恢复；未增加身份持久化或自动共享保存。

## 2026-10-21 用户反馈补充：本次变量草稿恢复

用户明确要求避免误返回后重新填写。同一浏览器标签页缓存已应用的普通业务参数草稿，按平台用户、项目、场景、环境和资产 commit 隔离；返回原上下文或刷新可恢复，其他上下文使用自身草稿。清除本次覆盖同时移除对应缓存，关闭标签页结束缓存。身份选择与运行输出不缓存，敏感字段不进入缓存。此决定替代原先切换上下文直接丢弃变量工作副本的行为。

步骤展示配置基线及本次值，编辑仍只写本次覆盖。默认配置维护沿用显式保存、revision/CAS及顶层替换；保存后未被本次覆盖的值同步到步骤，已有覆盖保留，并提供恢复配置值的入口。缓存不自动升级为共享配置。
